# Super Nintendo — Site

Site simples sobre o Super Nintendo: o console, as fitas (cartuchos) e os jogos que mais venderam.

Trabalho de CPW — Professor Leonardo Constantin · IFSUL.
Usando somente CSS e HTML padrão.

## Como rodar

Basta abrir o `index.html` no navegador. Não precisa de servidor nem de instalar nada.

## Estrutura

```
snes-site/
├── index.html      # página principal
├── css/
│   └── style.css   # estilos
└── imagens/        # imagens do site
```

## Tecnologias

- HTML5
- CSS3
- Fonte [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) (Google Fonts)
